# Studio

An AI-powered app builder web application. Describe your idea and let AI research, refine, and structure your concept into a ready-to-use prompt for application generation.

## Features

- **Prompt Input & Refining**: Describe your app idea with live character counting.
- **AI Selection Modes**: Choose between automatic model selection and manual model selection across OpenAI, Anthropic, and Google Gemini models.
- **Customizable Prompt Depth**: Quick spark, balanced structure, or deep blueprint.
- **Interactive Eye Tracking Animation**: Playful interactive UI elements.
- **Responsive Modern UI**: Built with pure HTML, CSS, and modern JavaScript.

## Getting Started

Simply open `index.html` in any web browser:

```bash
# Open in browser directly, or serve with a local server
python3 -m http.server 8000
```
